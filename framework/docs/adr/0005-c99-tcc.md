# ADR 0005 — C99 on tcc

Status: accepted.

## Context

tcc implements C99 and selected C11, but silently reports `199901L` for
`-std=c17`. Claiming C17 is false. gcc and clang are absent.

## Decision

Target C99 with `-std=c99 -D_POSIX_C_SOURCE=200809L`. Probe
`__STDC_VERSION__ == 199901L` and `_POSIX_VERSION == 200809L` at compile
time. Ban `-std=c17`.

## Consequences

- No C11/C17 features.
- The C gate compiles and runs both probes.
- cppcheck runs with `--std=c99`; astyle uses K&R with two spaces.
