== Overview

This repository contains the personal development environment bootstrap and
configuration — dotfiles — for +{org-name}+. It is the single source of truth
for shell configuration, editor setup, terminal multiplexer layout, prompt
theme, and development tooling defaults across all workstations.

The repository is governed by the framework defined in
<<STANDARDS.adoc,STANDARDS.adoc>> (v{standards-version}), which establishes the
toolchain, coding standards, and project structure conventions used throughout
this environment.

'''''

== Technology Stack

The environment is built on the toolchain prescribed by STANDARDS.adoc. Key
components include:

|===
| Category | Tool | Version

| Shell
| Nushell
| 0.112.2

| Editor
| Helix
| 25.07.1

| Version Control
| Jujutsu (jj)
| 0.41.0

| Build System
| just + xtask
| 1.51.0

| Environment
| Nix Flakes
| 26.05

| Language
| Rust
| 1.95.0 (Edition 2024)
|===

All classic Unix tools (grep, find, cat, sed, diff, ls, du, ps, top) are
replaced by Rust-native alternatives: ripgrep, fd, bat, sd, delta, eza, dust,
procs, bottom — configured through Nushell aliases in `config.nu`.

See <<STANDARDS.adoc#part-1-the-full-stack-decision,Part 1 of STANDARDS.adoc>>
for the full rationale.

'''''

== Getting Started

[horizontal]
Clone:: `jj git clone {repo-url}` or `git clone {repo-url}`
Bootstrap:: `nu scripts/dev-setup.nu` or `nix develop .`
Verify:: `nu scripts/check-deps.nu` or `nix flake check`

These steps install the Rust toolchain, Nushell, Helix, jj, and all supporting
utilities at the versions specified in the standard.
