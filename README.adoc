== Overview

This repository contains the personal development environment bootstrap and
configuration — dotfiles — for +{org-name}+. It is the single source of truth
for shell configuration, editor setup, terminal multiplexer layout, prompt
theme, and development tooling defaults across all workstations.

The repository is governed by the framework defined in
<<STANDARDS.adoc,STANDARDS.adoc>> (v{standards-version}), which establishes the
toolchain, coding standards, and project structure conventions used throughout
this environment.

== Detailed Getting Started

[horizontal]
Clone::     `jj git clone {repo-url}` or `git clone {repo-url}`
Bootstrap:: `nu scripts/dev-setup.nu`
Enter::     `nix develop --command /bin/sh` or `just shell-sh`
Verify::    `just doctor` or `nu scripts/check-deps.nu`

NOTE: Interactive `nix develop` is blocked on Alpine/musl (Nix stdenv
uses a glibc-linked bash as `NIX_BUILD_SHELL`).
Use `nix develop --command /bin/sh -c "<cmd>"` for one-off commands.
All `just` recipes route through `nix develop --command` automatically.

IMPORTANT: All development must use tools provided by the Nix flake.
Run `just doctor` after entering `nix develop` to verify hermetic environment.
If `just doctor` fails, check that you are inside `nix develop` and that
`nix flake check` passes. See `docs/platform-quirks/` for OS-specific notes.

These steps install the Rust toolchain (fenix 1.95.0), Nushell, Helix,
jj, and all supporting utilities at the versions specified in the standard.
All §1.4.2 tools are provided by `pkgsCross.musl64` Nix derivations with
store paths hardcoded in `config/nushell/env.nu`.

NOTE: MCP servers (context7, sequential-thinking, filesystem, memory)
activate automatically when opencode starts.
The GitHub MCP server requires a `GITHUB_TOKEN` environment variable.
Enter `nix develop` or run `just shell` to ensure `npx` is on PATH
before starting opencode for local MCP server support.
