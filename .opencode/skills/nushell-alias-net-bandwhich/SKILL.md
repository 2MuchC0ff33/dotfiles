# Nushell Alias: net = bandwhich

**STANDARDS.adoc reference:** §11.1 (line 3713)

The "ADDITIONAL RUST-NATIVE UTILITIES" section of config.nu defines:

```nushell
alias net = bandwhich
```

bandwhich is a network utilization TUI that shows per-process bandwidth.
Install via: `cargo install --locked bandwhich`
