# nushell-starship-init

## Description
Initialize Starship prompt in Nushell by caching its init script and sourcing it in `config.nu`.

## When to Load
Load this skill when configuring the Starship prompt integration in Nushell's `config.nu`.

## Source
STANDARDS.adoc §11.1 (lines 3677–3685), §11.4.1 (lines 3746–3811)

## Key Rules

- MANDATE: The `config.nu` MUST conditionally source the Starship init file from `~/.cache/starship/init.nu`.
- MANDATE: The Starship init file MUST be generated by running `starship init nu | save -f ~/.cache/starship/init.nu`.
- SHOULD: The source block MUST use `path exists` guard to handle missing init file gracefully.
- FORBIDDEN: Sourcing `starship init nu | ...` inline in `config.nu` (slows shell startup). Putting the init file inside the project repository (it's a user-local cache file).

## Rationale

Starship is the organization's prompt engine (see STANDARDS §11.4.1). The
recommended initialization pattern for Nushell is:

1. **Generate once**: `starship init nu | save -f ~/.cache/starship/init.nu`
   - This generates Nushell-compatible init code from Starship
   - Written to a cache file (not re-evaluated on every shell start)
   - `save -f` forces overwrite on update

2. **Source conditionally**:
   ```nushell
   if ($"($env.HOME)/.cache/starship/init.nu" | path exists) {
       source $"($env.HOME)/.cache/starship/init.nu"
   }
   ```
   - `path exists` check: If the init file hasn't been generated yet, Nushell
     starts without Starship (degraded prompt) rather than erroring
   - `source`: Loads the cached init code into the current shell session

This approach keeps shell startup fast (no subprocess spawn for `starship
init nu` on every terminal launch) while maintaining conditional safety.

## Example

```nushell
# In config.nu (ENVIRONMENT section):
if ($"($env.HOME)/.cache/starship/init.nu" | path exists) {
    source $"($env.HOME)/.cache/starship/init.nu"
}
```

Generation (run once, not in config.nu):
```bash
mkdir -p ~/.cache/starship
starship init nu | save -f ~/.cache/starship/init.nu
```
