# Nushell Alias: gui = jj Log

**STANDARDS.adoc reference:** §11.1 (line 3712)

The "ADDITIONAL RUST-NATIVE UTILITIES" section of config.nu defines:

```nushell
alias gui = jj log
```

This provides a TUI-like jj log view directly from the shell.
An alternative is the `gg` dedicated TUI (`cargo install --locked gg`).
